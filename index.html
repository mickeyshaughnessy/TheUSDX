Acme Redactors

Data Market API
Buy and sell datasets • Deliver through the cloaking device

Acme Redactors is a data market API for any dataset — government, commercial, research, or municipal. Sellers publish a pointer: metadata plus a private URL. Buyers browse the catalog (no source links) or request data in plain English (“traffic data for Colorado in 2025”). Smart matching ranks listings against metadata. After payment, the API returns the dataset URL, the records themselves run through the cloaking device, or both.

FOIA-compliant public records are a first-class path on the same interface, not a separate product. The cloaking device that makes a FOIA release segregable also protects commercial and research data. Privacy is priced per query — see Pricing at the bottom of this page.

Buyers

Browse listings without source URLs, or describe what you need. Matching is against metadata only. Pay to unlock the pointer and/or receive cloaked records.

Sellers

POST a title, description, keywords, geography, time range, price, and a URL. The URL is stored privately and never appears in browse or match responses.
Two-tier FOIA redaction (5 U.S.C. § 552) — also the default cloak for any records delivery: Classified, statutory, and operationally sensitive fields are blind-redacted with [b(Ex.N)] markers citing the applicable exemption — e.g. SSNs become [b(Ex.3)], clearance levels become [b(Ex.1)]. Personal privacy fields (names, addresses, dates of birth, phone numbers) are smart-redacted — replaced with realistic equivalents so record structure is preserved: “Marcus Thompson” becomes “David Ellison”, “412-67-8234” becomes [b(Ex.3)]. All non-exempt fields — case numbers, dates, titles, pay grades, dispositions — are released in full per the FOIA segregability requirement.

The Cloaking Device

At the core of delivery is the cloaking device: a layered identity-masking engine. Rather than blacking out sensitive fields, it substitutes realistic cover identities — different names, dates of birth, and contact details — so no individual can be traced through released documents while the record stays structurally useful. Built for FOIA; applied to any dataset you choose to deliver as records instead of (or in addition to) a raw URL.

Statutory exemptions are always enforced on government records; everything else is yours to dial up or down, per query. Commercial listings can use the same tiers.
